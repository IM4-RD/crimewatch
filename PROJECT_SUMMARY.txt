KEY FEATURES IMPLEMENTED
═════════════════════════════════════════════════════════════════════════════

✅ END-TO-END ENCRYPTION (E2E)
   • Client-side: AES-256-GCM symmetric encryption (WebCrypto API)
   • Key exchange: RSA-2048-OAEP wrapping of AES key
   • Server: Cannot read plaintext without explicit officer decryption request
   • Full implementation on both frontend (JavaScript) and backend (Python)

✅ OFFLINE-FIRST PWA
   • Service Worker for offline asset caching
   • IndexedDB for structured data storage
   • Automatic sync when connectivity returns
   • Background sync API for mobile platforms
   • Works fully offline, syncs transparently when online

✅ CROSS-PLATFORM
   • React-based responsive web PWA
   • Single backend API supports mobile (Flutter) and web
   • Native mobile apps can use same endpoints
   • Installable on iOS, Android, desktop

✅ SECURE AUTHENTICATION
   • JWT tokens with 24-hour expiry
   • Bcrypt password hashing (cost 12)
   • Role-based access control (public, officer, admin)
   • Refresh token rotation
   • Session tracking

✅ REPORT MANAGEMENT
   • Submit encrypted reports (payload never in plaintext on server)
   • Bulk sync for offline-first batch uploads
   • Status tracking (received → reviewing → investigating → resolved)
   • Media attachment with encryption
   • Officer notes and history tracking

✅ OFFICER & ADMIN TOOLS
   • Dashboard with real-time statistics
   • Filter/search reports by status, severity, type
   • Request decryption (only when explicitly accessing case)
   • Update report status and assign cases
   • User role management
   • Complete audit logging

✅ PRODUCTION READY
   • FastAPI with async handlers
   • SQLAlchemy ORM with prepared statements (SQL injection proof)
   • NGINX reverse proxy with SSL/TLS
   • Docker Compose orchestration
   • Rate limiting on sensitive endpoints
   • CORS, security headers, CSP
   • Separate database server (not containerized)
   • Dedicated media storage volume

API ENDPOINTS
═════════════════════════════════════════════════════════════════════════════

Authentication:
  POST   /api/auth/login              Login with email/password
  POST   /api/auth/register           Create new account
  POST   /api/auth/logout             Logout
  GET    /api/auth/me                 Get current user

Keys & Encryption:
  GET    /api/keys/public             Get server RSA-2048 public key for E2E

Reports:
  POST   /api/reports                 Submit encrypted report
  POST   /api/reports/bulk-sync       Bulk sync offline reports
  GET    /api/reports                 List user's reports
  GET    /api/reports/{id}            Get single report (encrypted)
  GET    /api/reports/{id}?decrypt    Request decryption (officer/admin)
  PATCH  /api/reports/{id}/status     Update status
  POST   /api/reports/{id}/media      Upload media file
  GET    /api/reports/{id}/history    Get status history

Statistics:
  GET    /api/stats                   Get aggregated stats

Admin:
  GET    /api/users                   List all users
  PATCH  /api/users/{id}/role         Update user role

Health:
  GET    /api/health                  Server status & version
